# Rishika Methi — BUDT748 Portfolio

A three-page personal website built with HTML, CSS, and Bootstrap 5.3.8.

## Pages

- Home: introduction, current studies, and areas of focus
- About: education, experience, skills, and selected project
- Contact: email and LinkedIn links

## View locally

Open `index.html` in a browser. Bootstrap CSS and JavaScript are included locally; no build step is required.

## Structure

- `index.html`, `about.html`, `contact.html`
- `css/styles.css`: custom styles
- `css/bootstrap.min.css`: Bootstrap styles
- `js/bootstrap.bundle.min.js`: Bootstrap mobile navigation

## Implementation

Responsive Bootstrap grid and collapsible navigation, current-page navigation indicators, semantic HTML, keyboard focus styles, and direct contact links. The site was authored directly in HTML/CSS; it was not exported from Figma.
